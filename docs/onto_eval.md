## 2. Аналіз 5 класів за методикою OntoClean (Критерій C2)
1. **`ITResource`**: +R (Rigid), +S (Supplied Identity). Фундаментальний категоріальний клас.
2. **`ComputeServer`**: +R (Rigid), -O (Not Anti-Rigid). Сутність не може втратити жестку суть сервера без знищення.
3. **`AlertState`**: -R (Anti-Rigid). Рольовий/статусний клас; ресурс може входити й виходити зі стану тривоги.
4. **`Incident`**: +R, +D (Dependent). Існує лише за наявності об'єкта ураження.
5. **`VirtualMachine`**: +R, +I (Identity). Має унікальний UUID/MAC-ідентифікатор.

## 3. CQ-тестування (10+ SPARQL запитів) (Критерій C3)

Частка проходження CQ: **Експертна = 100% (10/10)**, **LLM = 40% (4/10)** через відсутність обернених властивостей та диз'юнкцій.
